# LandSlidersRecomp
A full recompilation of the old mobile game Land Sliders by PrettyGreat

This repository contains restoration, compatibility, and maintenance work for the game Land Sliders.

Land Sliders and all original game assets, trademarks, and intellectual property remain the property of their original owners.

This project is intended for preservation, research, and educational purposes. No ownership of the original game is claimed.

## Current Status
- Game launches and is fully playable
- Character selection working
- Skybox shader restored
- CombinedShader restored
- Android ad dependencies bypassed for non-android devices
- UI shaders restored

## Known Issues
- Helicopter character causes loading failure
- UI layering issues remain
- Some shaders still require restoration
